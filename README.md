# 🌸 Soft Focus Widgets

Pastel, ADHD-friendly widgets for Notion: greeting clock, focus timer, breathing bubble, dopamine picker, day progress and sip tracker.

Gallery & embed links: https://hkcm91.github.io/soft-focus-widgets/

In Notion: `/embed` → paste a widget link. Add `?theme=light` / `?theme=dark` to force a theme, `?name=You` on the greeting.
